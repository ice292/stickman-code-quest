# 🧍 Stick Man Code Quest

เกมฝึกเขียนโปรแกรมแบบลากบล็อก (Blockly) พาสติกแมนเดินผ่านด่านไปถึงธง 🚩 มีทั้งหมด 12 ด่าน (ด่าน 11–12 ระดับยาก: เก็บเพชร, กุญแจ+ประตู, วาร์ป)
เริ่มจากเดินตรง → เลี้ยว → กระโดดข้ามหิน → ทำซ้ำ → ทำซ้ำจนกว่าจะถึง → เงื่อนไข ถ้า/ไม่อย่างนั้น

เล่นได้ที่: https://ice292.github.io/stickman-code-quest/
